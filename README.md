# Lab 8 : Threads et AsyncTask (Android)

Ce projet est une application Android simple pour apprendre a utiliser les threads et AsyncTask.

## Presentation
L'objectif est de faire des taches longues sans bloquer l'application pour l'utilisateur.

### Points cles
- Signature : Toutes les variables, IDs et ressources se terminent par _mouad.
- Fluidite : L'interface reste reactive meme pendant les traitements.

## Fonctionnalites
- Chargement d'image : Utilise un Thread et un Handler pour charger une image sans figer l'ecran.
- Calcul asynchrone : Utilise une AsyncTask avec une barre de progression.
- Test de reponse : Un bouton Toast pour verifier que l'interface n'est pas bloquee.
